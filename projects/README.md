# projects/ — 项目文件库

看板的项目文件统一放在这个目录下，**每个项目一个子文件夹，文件夹名与
data.js 中该项目的 `name` 完全一致**：

```
看板根目录/
├── index.html          ← 双击打开看板
├── data.js             ← 展示数据（由脚本/Workbuddy 生成）
├── config.js           ← 对接配置（手工维护）
└── projects/
    ├── 星链光子/
    │   ├── 星链光子-BP-v3.pdf
    │   ├── 光通信赛道扫描.xlsx
    │   └── 初筛评分表.docx
    ├── 麦禾智造/
    ├── 云枢数据/
    └── 恒芯半导/
```

## 规则

1. **新文件入库** = 把文件放进对应项目的子文件夹，然后在 data.js 该项目的
   `files` 数组中追加一条记录，`url` 填相对路径：
   `"projects/<项目名>/<文件名>"`。
2. **在线文档**（腾讯文档等）不放本目录，直接在 `url` 填完整 `https://` 链接。
3. 访谈纪要如果有文档（本地或在线），同样在 `interviewNotes[].url` 填链接。
4. `url` 留空的条目在看板上正常展示、但不可点击。
5. 本目录只放文件，不要放代码；data.js 的字段规范见仓库根目录 README.md。

> 交给 Workbuddy 维护时：它的任务就是执行第 1 条 —— 监测本目录的新文件，
> 并按规范更新 data.js。文件夹结构本身不要改。
